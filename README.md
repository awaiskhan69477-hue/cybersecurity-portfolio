# Awais Khan — Cybersecurity Portfolio

Professional personal portfolio for GitHub Pages.

## Files
- `index.html` — main portfolio
- `style.css` — responsive visual design
- `script.js` — navigation and subtle reveal animations
- `assets/resume.docx` — source resume

## Publish on GitHub Pages
1. Create a repository (for example `awais-cybersecurity-portfolio`).
2. Upload all files while preserving the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch** and choose `main` / root.
5. Save. GitHub will provide the public Pages URL.

## Personal photo
The current design uses an initials avatar so no photo is required. If you want to add your LinkedIn photo later, save it as:
`assets/profile.jpg`
and replace the `.avatar-fallback` block in `index.html` with an image.

## Notes
The portfolio intentionally lists certifications and training as text rather than hosting certificate files.
